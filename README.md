# Mainstream Digitals (MSD) Website

A cinematic, fully animated landing site for **Mainstream Digitals**, a creative agency for wedding, event, food and commercial photography, ad films and digital marketing.

Built with React and Vite. Animation work is split across three libraries, each with one job:

| Library | Responsibility |
| --- | --- |
| **GSAP + ScrollTrigger** | Scroll reveals, pinned sections, horizontal work reel, showreel expansion, parallax |
| **Three.js** | Hero scene: a tilted, curved ring of photo and video cards that reacts to mouse and scroll |
| **Framer Motion** | Page transitions, nav pill, menus, filters, lightbox, magnetic buttons, custom cursor |
| **Lenis** | Smooth scrolling, synced to GSAP's ticker |

## Pages

- **Home**: preloader with logo assembly, 3D hero, scroll-velocity marquee, word-fill statement, hover-image service list, pinned horizontal project reel, expanding showreel, marketing grid, process timeline, CTA
- **Work** (`/work`): animated category filters, editorial project grid with hover reels, full masonry "frames" wall with keyboard lightbox
- **Project** (`/work/:slug`): case-study page with cover, story, film, gallery and next-project link
- **Services** (`/services`): one section per service, deep-linkable with `#weddings`, `#commercial`, `#food`, `#events`, `#ads`, `#marketing`
- **About** (`/about`) and **Contact** (`/contact`)

## Getting started

Requires Node 18 or newer.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
npm run preview    # serve the build on http://localhost:4173
```

## Project structure

```
public/
  media/img/        optimized WebP photos (name.webp + name-sm.webp)
  media/vid/        short muted MP4 reels + JPG posters
scripts/
  optimize.mjs      converts original photos into the WebP set above
src/
  data.js           contact details, projects, services, process: edit content here
  media-meta.json   image dimensions generated by optimize.mjs
  App.jsx           router, Lenis, preloader, page transitions
  components/       HeroScene, Nav, Preloader, Cursor, Magnetic, Marquee, Footer, ...
  lib/              GSAP setup and the shared useScrollFx hook
  pages/            Home, Work, Project, Services, About, Contact
  index.css         design tokens, global UI
  pages.css         page and section styles
```

## Editing content

Most changes only need `src/data.js`:

- **Contact**: `CONTACT` (email, phone, WhatsApp link)
- **Projects**: `PROJECTS`. Each entry has a `slug`, `title`, `category`, `year`, `cover` image, optional `video`, `intro`, `services` and `gallery` list. Image names refer to files in `public/media/img` without the extension.
- **Services**: `SERVICES` and **process steps**: `PROCESS`

> The project titles and descriptions are placeholders written around the sample media. Replace them with real client work before launch.

### Adding photos

1. Put originals in a folder next to the project (the script reads `../devanshu-media-2026-10-27` by default).
2. Add `'original-file.jpg': 'new-name'` to the `map` in `scripts/optimize.mjs`.
3. Run `node scripts/optimize.mjs`. This writes `new-name.webp` (1800px) and `new-name-sm.webp` (700px) and updates `media-meta.json`.
4. Reference `new-name` in `src/data.js`.

### Adding videos

Keep clips short (8–12 s), muted, around 720px wide and H.264. With `ffmpeg-static` (already a dev dependency):

```bash
"$(node -p "require('ffmpeg-static')")" -ss 5 -t 10 -i input.mp4 -an -vf "scale=720:-2,fps=30" -c:v libx264 -crf 28 -pix_fmt yuv420p -movflags +faststart public/media/vid/name.mp4
"$(node -p "require('ffmpeg-static')")" -ss 6 -i input.mp4 -frames:v 1 -vf scale=720:-2 public/media/vid/name.jpg
```

## Performance and accessibility

- The WebGL hero only runs on desktop widths; phones get a lightweight floating-reel version.
- `prefers-reduced-motion` disables smooth scroll, the 3D scene and scroll animations.
- Videos play only while on screen; images below the fold are lazy-loaded.
- Three.js, GSAP, Framer Motion and React are split into separate cached chunks.

## Deployment

It's a static single-page app. Any static host works as long as unknown paths fall back to `index.html` so routes like `/work` survive a refresh. On Vercel, a `vercel.json` with this rewrite does that:

```json
{ "rewrites": [{ "source": "/((?!media/|assets/).*)", "destination": "/index.html" }] }
```
